# Experimento de CSS classless para a homepage

Este repositório contém um experimento prático usando CSS classless (como o `water.css`) para estilizar uma página HTML básica (`index.html`). O objetivo principal é avaliar a estética e a estrutura semântica dos elementos HTML padrão.

## Convenções do Projeto

Este projeto segue diretrizes rigorosas documentadas em [`AGENTS.md`](./AGENTS.md). Algumas das principais diretrizes incluem:
- Gerenciamento estrito de ferramentas usando `mise`.
- Formatação e linting executados via `mise run lint`.
- Estrutura de Pull Requests padronizada.
- Entradas e responsabilidades claramente definidas.

Consulte o arquivo `AGENTS.md` para as regras completas e atualizadas.
